# 多可 Carousel 配色

| Token | Hex | 用途 |
|-------|-----|------|
| warm_paper | `#F2EDE4` | Cover、Index、CTA 背景 |
| cool_stone | `#EDEEE8` | Content、Visual 背景 |
| accent_brown | `#8B7355` | 標籤、細線、點綴 |
| charcoal | `#2C2C2A` | Accent 頁背景 |
| text_primary | `#2C2C2A` | 淺底主文字 |
| text_on_dark | `#F2EDE4` | 深底主文字 |
| text_muted | `#8B7355` | 副標、頁碼 |
| step_number | `#E8E0D4` | 大號裝飾數字（比背景深一階） |
| photo_placeholder | `#C4B8A8` | Visual 頁照片區（低飽和） |

禁止純白 `#FFFFFF`、純黑 `#000000` 作為全頁背景。
