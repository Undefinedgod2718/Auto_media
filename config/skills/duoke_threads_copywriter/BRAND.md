# 多可競爭力（Talking2Win）品牌與寫作規範

## 品牌核心定位

多可競爭力的核心價值：**因腦施教 × 教練引導**，幫助家長理解孩子的大腦發展狀態，找到更適合的學習與適應路徑。

- 多可不是「孩子出問題才去的地方」，而是「幫助孩子建立未來競爭力的兒童發展教育平台」。
- Threads 功能：養**觀點聲量**與**情緒共鳴**，不是直接賣課。

## 主要受眾（TA）

**首要 TA：** 3–8 歲孩子的焦慮型家長（幼兒園大班～國小低年級）。狀況：坐不住、講不聽、分心、情緒停不下來、聽得懂但做不到。

深層感受：不知道孩子怎麼了、怕罵傷親子、很努力卻沒用。多可應承接這個情緒。

**次要 TA：** 準備升小一的家長、重視教育品質的家長、幼兒園老師與園長。

## Threads 寫作鐵則

### 前 26 字 = 標題

每一則前 26 字決定是否繼續讀；須能**獨立**勾住陌生家長。有效鉤子：

- 日常場景切入
- 反直覺事實
- 反直覺場景
- 現實對照提問

### 5 則結構（固定）

| 則序 | 功能 |
|------|------|
| 1 | 鉤子：具體場景，「說的就是我」 |
| 2 | 研究或事實：白話，非學術腔 |
| 3 | 機制解釋：為什麼；**勿**以感統／前庭／神經術語開場 |
| 4 | 現實對照：對照自家孩子 |
| 5 | 多可視角收尾：品牌出現在情感最柔軟處，非第一句 |

### 語氣

- 不說教、不推銷、少專業詞彙；像懂腦科學的朋友。
- 短句、換行節奏。
- 用「腦科學告訴我們」「研究再次確認」，避免「研究指出」「根據文獻」。

### 禁語與禁忌

**不能說：**

- 孩子有問題、不正常、需要被修復
- 「改善發展遲緩」「治療過動」「讓孩子恢復正常」
- 「改善過動」「治療專注力」「保證提升」等醫療化或保證效果
- 一開始就感統術語；要先讓家長覺得被理解

## 五條內容主線（每篇擇一）

| 主線 | 焦點 |
|------|------|
| 家長痛點線 | 坐不住、分心、情緒、講不聽（流量） |
| 小一準備線 | 學習準備力、專注、聽指令、情緒穩定（講座轉換） |
| 因腦施教線 | 不是不想學、大腦還沒準備好（品牌定位） |
| 親師溝通線 | 老師觀察、親師說法（B2B 轉介） |
| 案例轉譯線 | 安全描述真實改變（信任與成交） |

## 核心穿透句

> 原來孩子不是故意不聽話，而是他的大腦還沒有準備好。

每篇應讓讀者讀完後感受到這句話的重量（可不逐字寫出）。

## IG Carousel 視覺：基礎風格 Prompt（固定模組）

每次生成圖像 Prompt 時，**完整複製**以下區塊，再拼接當頁類型模板與文案。

```
【視覺風格】
極簡主義編輯風格海報（Editorial Minimalism Poster）。
背景色為溫暖米白色（#F2EDE4）或冷灰石色（#EDEEE8），禁止純白或純黑背景。
低飽和、紙質感，輕微膠卷底片氛圍。
配色 2 種以內：主色暖米白或冷石灰，點綴土褐色（#8B7355）；
強調頁可用深炭黑（#2C2C2A）配淺色字。

【字體與排版】
主標：無襯線粗體 Bold，字級大、對比強。
副標與內文：Regular 細體、字距寬鬆。
角落標注：極小字 9–11px，大寫英文 letter-spacing。
左側邊緣：垂直旋轉 90° 系列名標注。
禁止超過三種字體層次。

【排版結構】
左上：頁碼「01 / 06」；右上：品牌或系列名（可細框）。
左側：垂直主題文字；中央偏左：主標 + 類別標籤 + 短段內文；主標尾可加「·」。
底部：細線 + 引言「" 文字 "」；右下：▼ 或序號。

【圖像（若有）】
黑白或低飽和棕褐；置中偏右 40–60%；電影感顆粒；與文字 overlap。

【裝飾】
僅允許：細橫線、小三角 ▼、短直線、大號淡色步驟數字。
禁止：漸層、陰影、發光、花邊、插畫角色。

【氛圍關鍵字】
editorial, typographic, film grain, vintage paper texture,
quiet luxury, swiss design, minimal, calm and trustworthy
```

## 頁面類型（A–F）

- **A Cover**：Carousel 第 1 張，破題
- **B Index**：第 2 張，目錄 3–5 章節
- **C Content**：論點頁，冷石灰底，INSIGHT 等標籤
- **D Accent**：金句強調，深炭黑底，每組最多 1–2 張
- **E Visual**：圖文頁，照片描述 + 圖說
- **F CTA**：最後一張，行動號召與 @帳號

帳號預設系列名可用：**Talking2Win** / **多可競爭力**（若 TASK 未指定）。
