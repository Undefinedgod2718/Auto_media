- Canvas: **1080×1080** pixels.
- File: **PNG or JPEG**, max **8 MB**.
- No SVG, no HTML, no Markdown saved as the image file.
- Flat / editorial layout; high contrast; readable on mobile.
- Brand sidebar optional: `PARENTING & BRAIN SCIENCE`, page index `NN / 06`, `DOKO.` per PALETTE.
- No scripts, animation, or video in the static file.
- Self-contained single image file at the instructed path (`post.png` or `post.jpg`).
