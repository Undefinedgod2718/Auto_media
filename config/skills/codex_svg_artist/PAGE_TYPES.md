# 頁面類型模板（A–F）

套入文案後，與 `VISUAL_BASE.md` 合併為單一 Prompt。`[總頁數]`、`[頁碼]` 依規劃表替換。

---

## 【類型 A】封面頁 Cover

**時機：** 第 1 張，破題

```
【頁面類型】封面頁 Cover
【背景】暖米白（#F2EDE4）
【頁碼】左上角標注：01 / [總頁數]
【右上角】品牌識別：[帳號或系列名稱]
【側邊文字】垂直排列：[主題系列名，大寫英文]
【主標題】[6–15 字]
【類別標籤】[策略 / 洞察 / 案例 / 提醒]
【破題副文】[15–25 字]
【底部引言】"[金句或 slogan]"
【視覺風格】套用基礎風格 Prompt
```

---

## 【類型 B】目錄頁 Index

**時機：** 第 2 張

```
【頁面類型】目錄頁 Index
【背景】暖米白（#F2EDE4）
【頁碼】左上角：02 / [總頁數]
【頁面標題】本篇內容（極小字）
【目錄列表】
  01  [章節名稱 1] →
  02  [章節名稱 2] →
  03  [章節名稱 3] →
  04  [章節名稱 4] →
  05  [章節名稱 5] →
每行之間 0.5px 細線分隔
【視覺風格】套用基礎風格 Prompt
```

---

## 【類型 C】內容頁 Content

**時機：** 第 3–6 張（可多張）

```
【頁面類型】內容頁 Content
【背景】冷石灰（#EDEEE8）
【頁碼】左上角：0[頁碼] / [總頁數]，右下角：▼
【大號裝飾數字】頁碼放大，極淡 #E8E0D4
【標籤】[INSIGHT / STRATEGY / EXAMPLE]
【標題】[8–16 字]
【內文】[60–80 字]
【底部細節】細線 + 「CONT.」
【視覺風格】套用基礎風格 Prompt
```

---

## 【類型 D】強調頁 Accent

**時機：** 金句；**每組最多 1–2 張**

```
【頁面類型】強調頁 Accent
【背景】深炭黑（#2C2C2A）
【頁碼】左上角：0[頁碼] / [總頁數]（淺灰小字）
【標籤】KEY POINT
【主引言】"[15–30 字金句]"
【補充說明】[1–2 句，更淡更小]
【底部裝飾】細線 + 英文延伸（可選）
【視覺風格】套用基礎風格 Prompt
```

---

## 【類型 E】圖文頁 Visual

**時機：** 視覺節奏、照片說明

```
【頁面類型】圖文頁 Visual
【背景】冷石灰（#EDEEE8）
【頁碼】左上角：0[頁碼] / [總頁數]
【圖片描述】[情境：家長與孩子／教室等；黑白低飽和；電影顆粒；俯拍或側拍]
【圖片位置】置中偏右 50%，與左側文字 overlap
【標題】[10–20 字]
【內文】[30–50 字]
【視覺風格】套用基礎風格 Prompt
```

---

## 【類型 F】結尾頁 CTA

**時機：** 最後一張

```
【頁面類型】結尾頁 CTA
【背景】暖米白（#F2EDE4）
【頁碼】[總頁數] / [總頁數]
【標籤】TAKE ACTION（極小字置中）
【主文】[行動號召，如：想了解孩子的大腦節奏，歡迎私訊。]
【帳號】@Talking2Win
【底部裝飾】細線 + slogan（可選）
【視覺風格】套用基礎風格 Prompt
```

---

## 建議 8 頁配置（500 字內容級）

| 頁 | 類型 | 字數／功能 |
|----|------|------------|
| 1 | A Cover | 主題 + ~20 字破題 |
| 2 | B Index | 3–5 章節名 |
| 3 | C Content | 60–80 字，問題背景 |
| 4 | C Content | 60–80 字，核心洞察 |
| 5 | D Accent | 金句 15–30 字 |
| 6 | C Content | 60–80 字，方向或案例 |
| 7 | E Visual | 圖說 30–50 字 |
| 8 | F CTA | 行動 + 帳號 |

深度說服文案放 Instagram **caption**，Carousel 負責吸引。
