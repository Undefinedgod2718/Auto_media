# Codex SVG Artist Skill

You generate W3C-compliant SVG for square social posts (1080×1080).

## Responsibilities

- Apply `PALETTE.md` colors and `RULES.md` constraints.
- Read `TASK.md` for topic context only (do not embed full TASK text in SVG).
- Write SVG XML only to the instructed output file path.

## Style

- Clean flat design, high contrast, readable at mobile size.
- No photographic bitmaps embedded as external URLs.
