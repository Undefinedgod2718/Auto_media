# 基礎風格 Prompt（固定模組）

> 生成**每一張** Carousel / 社群圖時，將以下區塊**完整複製**放在該頁專屬內容之前。

```
【視覺風格】
極簡主義編輯風格海報（Editorial Minimalism Poster）。
背景色為溫暖米白色（#F2EDE4）或冷灰石色（#EDEEE8），禁止使用純白或純黑背景。
整體色調為低飽和、紙質感，帶有輕微的膠卷底片氛圍。
配色限制在 2 種以內：主色為暖米白或冷石灰，點綴色為土褐色（#8B7355），
強調頁可使用深炭黑背景（#2C2C2A）搭配淺色文字。

【字體與排版】
主標題：無襯線粗體（Bold），字級大、視覺佔比高，與頁面形成強烈對比。
副標題與說明文字：細小、間距寬鬆，字體使用 Regular 細體。
角落標注：極小字（9–11px 等比例），使用字母間距拉寬（Letter-spacing）的大寫英文。
側邊裝飾文字：垂直排列，旋轉 90 度，放置於左側邊緣，做為主題系列名稱標注。
禁止使用多於三種字體層次。

【排版結構規範】
左上角：頁碼標注，格式為「01 / 06」
右上角：品牌識別標記或系列名稱，可用細框線框住（如 DOKO.）
左側邊緣：垂直旋轉的細小主題文字
頁面中央偏左：主標題（最大）+ 類別標籤（如 [noun] 或 [INSIGHT]）+ 短段落內文
主標題結尾可加細小圓點（·）作為收尾符號
頁面底部：細線分隔後放置引言或行動號召語，引言格式為「" 文字內容 "」
右下角：頁碼箭頭或序號（▼）

【圖像風格（若有圖片）】
若頁面需要搭配照片，照片使用黑白或低飽和棕褐色調。
照片位置：置中偏右，佔頁面 40–60% 面積，不滿版。
照片帶有輕微的電影感或舊底片顆粒質感。
照片與文字區域有明顯的重疊交錯（Overlap）設計，非單純並排。

【裝飾元素】
裝飾極少，僅允許以下元素：
- 細橫線（0.5px–1px）
- 小型實心三角形（▼）
- 短直線段作為章節分隔
- 大號淡色數字作為步驟裝飾（顏色比背景深一階，如 #E8E0D4）
禁止使用漸層、陰影、發光、花邊、插圖角色。

【整體氛圍關鍵字】
editorial, typographic, film grain, vintage paper texture,
quiet luxury, swiss design, minimal, architectural,
business professional, calm and trustworthy
```
