# 多可 Carousel 圖像生成 — 品牌與約束

## 受眾（圖像文案語氣）

3–8 歲孩子家長；焦慮但願意理解孩子。視覺文案避免醫療化、標籤化、保證成效。

## 色調一致

- 同一組 Carousel：**不要**封面暖米白、下一張突然冷藍或高飽和。
- Content / Visual 用冷石灰 `#EDEEE8`；Cover / Index / CTA 用暖米白 `#F2EDE4`。
- Accent（`#2C2C2A`）每組 **最多 1–2 張**。

## 字體建議（軟體允許時）

| 層級 | 字體 |
|------|------|
| 主標 | Neue Haas Grotesk / Aktiv Grotesk Bold |
| 內文 | GT America / Söhne Regular |

圖像 AI 無法指定時，在 Prompt 中寫「geometric sans-serif bold headline, humanist sans body」。

## 照片

- 實拍上傳前：黑白或低飽和濾鏡。
- Prompt 描述：避免卡通、3D 角色、廉價剪貼風。

## Canva

可先建立品牌套件儲存色碼：`#F2EDE4`、`#EDEEE8`、`#8B7355`、`#2C2C2A`。

## 禁止

- 漸層、發光、花邊、吉祥物
- 純白／純黑滿版背景
- 「治療」「恢復正常」「保證提升」等用語出現在圖上文字
